# Telegram Post Data Collector

Скрипт для автоматичного періодичного збору метаданих, переглядів та реакцій з постів у Telegram-каналі. Логіка розділена на парсер (`parser.py`) та модуль бази даних (`database.py`).

## Функціонал
* Періодичний запуск кожні 15 хвилин (налаштовано через асинхронний цикл).
* Збір інформації про останні 100 постів каналу (захист від проблем з боку Telegram API).
* Збереження даних у локальну базу даних **SQLite** (`studrada_stats.db`).
* Збір `post_id`, дати публікації, кількості символів, переглядів, наявності медіафайлів, посилань та кількості емоджі.

## Структура бази даних (SQLite)
Дані зберігаються в локальній базі `studrada_stats.db`, яка розділена на дві пов'язані таблиці:
* `posts` – містить основні метадані кожного поста (`post_id` є PRIMARY KEY).
* `reactions` – залежна таблиця для динамічного збереження емоджі та їхньої кількості. Пов'язана з першою таблицею через **Foreign Key** (`post_id`).

## Інсталяція та запуск

1. **Розпакуйте архів з проєктом.**
2. **Встановіть необхідні залежності:**
   ```bash
   pip install -r requirements.txt
   ```
3. **Введіть власні дані.** (`.env`)
4. **Введіть назву Telegram-каналу.** (`parser.py`)
5. **Запустіть скрипт:**
   ```bash
   python3 parser.py
   ```
